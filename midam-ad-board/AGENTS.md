# 프로젝트 작업 지침

- 새로운 프로그램에는 프로젝트 폴더 안에 History 파일을 만들고 변경·복원 기록을 보존한다.
- AI 모델 이미지 요청에서 사용자가 아이폰처럼/실사처럼/일상 실사 표현을 사용하면 docs/iphone-daily-prompt.md의 사용자 지정 일상 아이폰 프롬프트를 적용한다. 이전의 광고 모델 포즈·스튜디오 화보 기본값보다 이 지시를 우선한다.
- 생성 결과는 항상 웹 스토리보드에 등록하고 제작일·업종·키워드·스타일을 함께 표시한다. 기존 이미지 원본과 생성 프롬프트를 보존한다.
- 상품 참조와 얼굴 참조의 역할을 분리하며, 가상 모델을 실제 사람이나 실제 촬영 사진으로 소개하지 않는다.
